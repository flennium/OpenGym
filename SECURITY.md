# Security policy

Please do not open public issues containing member data, database copies, PINs, or exploitable details. Report security concerns privately through GitHub's security advisory feature for this repository.

OpenGym is designed for a trusted local workstation. Use operating-system account protection and full-disk encryption, restrict access to backups, and install only releases obtained from this repository. Biometric recognition is not provided by the current release and must not be represented as active.
