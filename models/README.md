# Face recognition models

`buffalo_sc` is an InsightFace model pack used for local face detection and recognition.
The pretrained weights are provided for non-commercial research and learning use; they
are not covered by the MIT license of the InsightFace source code. Obtain separate model
rights before using or redistributing OpenGym commercially.

Source: https://github.com/deepinsight/insightface/releases/tag/v0.7
